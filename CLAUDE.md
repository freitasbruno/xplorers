# XPlorers

A platform for accessing knowledge bites — small classes directed at younger audiences but open to anyone curious, designed to spark discussion during commutes or casual moments.

**Audience:** Parents, children, and curious minds of all ages.
**Language:** European Portuguese (pt-PT)
**Base path:** `D:\CLAUDE\xplorers`

---

## Stack

- **Backend:** Pure PHP (no framework) — includes for shared layout, data in JSON files
- **Frontend:** Vanilla JS + Tailwind CSS (CDN) + Inter font (Google Fonts)
- **Charts:** Chart.js (CDN, used in individual lesson pages)
- **Hosting:** Hostinger Premium shared hosting
- **Deployment:** GitHub Actions + FTP/SFTP to Hostinger

See `.claude/memory/techstack.md` for full details.

---

## Project Structure

```
/
├── index.php            # Catalog / homepage
├── lesson.php           # Lesson viewer (shared template)
├── quiz.php             # Quiz for a given lesson
├── includes/
│   ├── header.php
│   └── footer.php
├── data/
│   ├── lessons.json     # All lesson metadata
│   └── quizzes/         # Per-lesson quiz data (JSON)
├── lessons/             # Generated lesson content files (PHP)
├── admin/               # Ingest tool (password-protected)
├── assets/
│   ├── css/
│   └── js/
└── reference/           # Source materials (not deployed)
```

## Content Pipeline

Lessons are generated by Google Gemini using a custom prompt (see `.claude/memory/notes.md`).
Output is markdown. The ingest tool converts markdown → PHP lesson file + quiz JSON + catalog entry.

---

## Conventions

- All user-facing text in **pt-PT**
- Tailwind via CDN — no build step
- Lesson filenames: `[Category]_[NNN].php` (e.g. `Cosmos_001.php`)
- Quiz data: `data/quizzes/[Category]_[NNN].json`
- Lesson metadata in `data/lessons.json`
