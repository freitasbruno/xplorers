# Feature: Quiz Engine

**Slug:** `quiz-engine`
**Status:** pending
**Depends on:** `layout-foundation`

## Goal

A generic, interactive quiz renderer. Questions are stored in per-lesson JSON files. The engine loads the correct file and handles the full quiz experience — no per-lesson custom code needed.

## Flow

1. User arrives at `quiz.php?lesson=cosmos_001`
2. PHP loads `data/quizzes/cosmos_001.json`
3. JS engine renders questions interactively
4. On completion: score shown, correct answers revealed with explanations
5. "Voltar à aula" link back to the lesson

## Interaction design

- Questions shown one at a time (card flip style or step-through)
- Options as large tap-friendly buttons (important for mobile)
- On selection: immediate visual feedback — correct (green) / wrong (red) + explanation appears
- Progress bar or step indicator (e.g. "3 / 6")
- Final screen: score, summary of wrong answers, CTA back to lesson

## Data contract

`data/quizzes/[lesson_id].json`:

```json
{
  "lesson_id": "cosmos_001",
  "questions": [
    {
      "q": "Question text",
      "options": ["A", "B", "C", "D"],
      "correct": 1,
      "explanation": "Why this is correct."
    }
  ]
}
```

## Files

| File | Purpose |
|------|---------|
| `quiz.php` | Shell — loads JSON, passes to template |
| `assets/js/quiz.js` | Generic engine: render, interaction, scoring |

## Notes

- No login, no server-side score storage (Phase 1)
- Results optionally stored in localStorage for progress tracking (Phase 3)
- Quiz JSON files generated by ingest tool; can also be written manually
- Typical use: read on Monday, quiz on Wednesday
