# Feature: Quiz

**Slug:** `quiz`
**Status:** pending
**Depends on:** `lesson-detail`

## Goal

Per-lesson quiz, accessible from the lesson detail page tab bar. Typically used on Wednesday after Monday reading.

## Format

- 5–8 multiple choice questions per lesson
- One correct answer per question
- Questions stored in `data/quizzes/[topic_slug]_[NNN].json`
- No login required — results shown inline, not persisted server-side

## Flow

1. User opens quiz from lesson tab bar
2. Questions shown one at a time (or all at once — TBD)
3. On submit: score shown, correct answers revealed with explanation
4. "Voltar à aula" link back to lesson

## Quiz JSON structure

```json
{
  "lesson": "cosmos_001",
  "questions": [
    {
      "q": "O que é um vácuo?",
      "options": ["A", "B", "C", "D"],
      "correct": 0,
      "explanation": "..."
    }
  ]
}
```

## Notes
- Quiz data generated by ingest tool (from Gemini markdown output)
- Results can optionally be stored in localStorage for progress tracking (Phase 3)
